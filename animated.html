Animated sticker test

Try each button, paste into a Teams chat with Ctrl+V (Cmd+V on Mac), and note which one moves.

What each button does

  1. A. Copy as link puts only a web image (pointing at the GIF on this site) on the clipboard. If Teams fetches it, it should move.
  2. B. Copy as link + picture also adds a still picture as a backup. Teams might pick either one.
  3. C. Download GIF saves the file. Drag it from your downloads bar into the Teams chat. This one should always move.
  4. You can also drag the moving picture straight from this page into the Teams chat box.
